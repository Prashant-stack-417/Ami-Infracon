# 📏 Spacing

## 1. Core Scale
We strictly adhere to the default Tailwind spacing scale (based on `0.25rem` / `4px` increments).
- `p-1` = 4px
- `p-2` = 8px
- `p-4` = 16px
- `p-6` = 24px
- `p-8` = 32px

## 2. Container Padding
- **Mobile:** `px-4 py-6`
- **Tablet:** `sm:px-6 sm:py-8`
- **Desktop:** `md:px-8 md:py-12 lg:px-12`

## 3. Component Spacing
- **Cards:** `p-4` or `p-6` internally.
- **Forms:** `gap-4` between standard inputs, `gap-6` between fieldsets.
- **Buttons:** `px-4 py-2` for standard buttons, `px-3 py-1.5` for small buttons.
