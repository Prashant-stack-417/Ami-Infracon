# 🎨 Design System

## 1. Overview
The Ami Infracon Design System is built primarily on **Tailwind CSS 4**. The goal is a highly functional, readable, and professional interface tailored for B2B procurement and internal administration.

## 2. Core Principles
- **Functionality First:** Data density matters. Admins and buyers need to see order details clearly without excessive white space.
- **Consistent Visual Language:** Re-use standard Tailwind utility classes to avoid fragmentation.
- **Responsive Design:** Mobile-friendly by default, but optimized for desktop/tablet (primary platforms for B2B users).

## 3. Tooling
- **Framework:** Tailwind CSS v4.
- **Components:** Custom built via React components.
- **Icons:** `lucide-react` or similar SVG-based icon libraries.
- **Animations:** `animejs` for micro-interactions.
