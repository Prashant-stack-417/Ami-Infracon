# 🚚 Admin Orders
- **List View:** Table of orders (Order ID, User, Date, Total, Status, Actions).
- **Status Badges:** Color-coded (Pending=Yellow, Processing=Blue, Shipped=Green, Cancelled=Red).
- **Detail Modal:** Allows admin to view items and change status (triggers update to user's timeline).
