# 📦 Admin Products
- **List View:** Table of all products (Image, Title, SKU, Price, Stock, Actions).
- **Toolbar:** "Add New Product" button, "Upload CSV" button, Search bar.
- **Form View:** Modal or separate page. Inputs for all product schema fields, plus image dropzone (`multer`).
