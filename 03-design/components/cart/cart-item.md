# 🧩 Cart Item

## 1. Description
The `Cart Item` component is a reusable UI element for the Ami Infracon platform.

## 2. Props & State
- **Variants:** Primary, Secondary, Outline, Ghost (where applicable).
- **Sizes:** Small (`sm`), Medium (`md` - default), Large (`lg`).
- **State:** Disabled, Active, Loading.

## 3. Tailwind Implementation
- Utilizes core Tailwind CSS 4 utility classes.
- Follows accessible contrast and focus ring guidelines (`focus:ring-2 focus:ring-blue-500`).
